安装 / 设置

配置可通过配置文件或环境变量提供，细节见这里。配置文件模板在这里。

大部分配置也可以通过内置 Web UI 控制台完成——见下文首次运行。

Docker（推荐）

镜像发布在 GitHub Container Registry（GHCR）上。拉取后使用主机网络运行，这样它能访问局域网内的 Frigate 和 MQTT：

docker pull ghcr.io/izerok/frigate-notify-plus:v0.1.2
docker run -d --name frigate-notify-plus --network host \
  -v /srv/frigate-notify-plus:/data \
  -e TZ=Asia/Shanghai \
  ghcr.io/izerok/frigate-notify-plus:v0.1.2

把一个主机目录挂载到 /data（将 /srv/frigate-notify-plus 替换为你的路径）。数据目录存放 config.yml、logs/ 和 mute.json，因此配置和日志在容器重建后依然保留——删除容器不会删除数据。无需再挂载 config.yml 文件。

或者使用 compose：

services:
  frigate-notify-plus:
    image: ghcr.io/izerok/frigate-notify-plus:v0.1.2
    container_name: frigate-notify-plus
    network_mode: host
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - /srv/frigate-notify-plus:/data
    restart: unless-stopped

Tar 包安装（离线）

每个版本还会把 Docker 镜像作为 .tar.gz 文件发布在 Releases 页面，与 sha256sums.txt 一起提供，适用于无法访问镜像仓库的主机。下载所需版本的 tar 包，校验其校验和，然后加载并运行：

curl -LO https://github.com/izerok/frigate-notify-plus/releases/download/<tag>/<tar.gz>
sha256sum -c sha256sums.txt
docker load -i <tar.gz>

tar 包内镜像的标签为 frigate-notify-plus:webui-<short-sha>（例如 frigate-notify-plus:webui-c13eaec）。按上面的方式运行，改用这个本地镜像标签即可。

数据目录可通过 FN_DATA_DIR 环境变量（或 -d 参数）更改，配置文件位置仍可通过 FN_CONFIGFILE 环境变量（或 -c 参数）覆盖——例如，继续使用单个挂载的配置文件：

services:
  frigate-notify-plus:
    image: ghcr.io/izerok/frigate-notify-plus:v0.1.2
    network_mode: host
    environment:
      FN_CONFIGFILE: /app/config/config.yml
      TZ: Asia/Shanghai
    volumes:
      - /path/to/config_directory:/app/config
    restart: unless-stopped

Note

敏感信息（如密码）可通过环境变量或 docker secrets 配置。

环境变量列在配置文件参考中。

对于 docker secrets，先配置好你的 secret，然后把相应的环境变量指向 secret 文件。例如，如果你有一个名为 mqtt_password 的 secret，想把它提供给 frigate-notify-plus：

services:
  frigate-notify-plus:
    image: ghcr.io/izerok/frigate-notify-plus:v0.1.2
    environment:
      FN_FRIGATE__MQTT__PASSWORD: /run/secrets/mqtt_password

首次运行

Web UI 控制台运行在 8000 端口，默认启用。在局域网内的浏览器中打开 http://<host>:8000。

如果数据目录里还没有配置，应用会以设置模式启动，向导会带你完成：

  1. Frigate 服务器地址（它会检查该地址是否响应 /api/version）
  2. 事件来源——MQTT 或 Frigate Web API
  3. 你的第一个通知渠道（例如 Telegram）
  4. 一条测试通知

控制台没有鉴权，仅供局域网使用——不要把 8000 端口暴露到公网。

定时 GenAI 总结按容器的本地时间运行。把容器时区设为与你的 Frigate 主机一致，例如 -e TZ=Asia/Shanghai。

本地运行

本 fork 不发布独立二进制文件。不用 Docker 运行时，从源码构建（Go 1.25+）：

go build -tags goolm -o frigate-notify-plus .
./frigate-notify-plus

默认情况下，应用会在同一目录下查找名为 config.yml 的配置文件。设置了数据目录时（-d <dir> 或 FN_DATA_DIR），配置文件为 <dir>/config.yml，日志写入 <dir>/logs/frigate-notify.log（10 MB 轮转，保留 5 个备份）。

可用 -c 参数手动指定配置文件名或位置：

./frigate-notify-plus -c <new-config-file-location>

或使用数据目录：

./frigate-notify-plus -d /srv/frigate-notify-plus
